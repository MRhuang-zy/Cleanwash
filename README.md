# Cleanwash

**Cleanwash 可以代替胖乖生活 App 完成日常洗衣。扫机器上的码，选好模式，核对金额，直接打开支付宝付款。**

**0 广告 · 0 会员。洗衣、查订单和设备状态，也支持设备提供的 0 元筒自洁。**

**20 秒是已登录后从扫码到支付的操作目标，实际用时随网络和设备状态变化。**
